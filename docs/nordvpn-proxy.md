# NordVPN как прокси в Profile Workspace

Поддержка доступна в версии **0.1.1 и новее**. Приложение NordVPN для этого подключения включать не нужно. SOCKS5 применяется только к профилям, которым вы его назначили.

## 1. Получите служебные данные NordVPN

Откройте [Nord Account](https://my.nordaccount.com/), выберите NordVPN и найдите настройку ручного подключения — **Set up NordVPN manually / Service credentials**. Если кабинет запросит подтверждение по почте, пройдите его. Скопируйте служебные **Username** и **Password**. Обычные почта и пароль от входа в Nord Account для прокси не подходят. Не отправляйте служебный пароль в чат: введите его в поле пароля программы.

Названия разделов кабинета могут меняться. Актуальные адреса серверов и ссылка на служебные данные есть в [официальной инструкции NordVPN](https://support.nordvpn.com/hc/en-us/articles/20195967385745-NordVPN-proxy-setup-for-qBittorrent). Настройки ниже проверены по этой инструкции 8 ноября 2026 года.

## 2. Создайте прокси

Откройте **Прокси → Новый прокси** и заполните поля:

| Поле | Значение |
| --- | --- |
| Название прокси | Например, `Nord · Нидерланды` |
| Протокол | `SOCKS5` |
| Сервер | `nl.socks.nordhold.net` |
| Порт | `1080` |
| Логин | Служебный Username из Nord Account |
| Пароль | Служебный Password из Nord Account |

В поле сервера вводите только домен, без `socks5://`, порта и пароля. Нажмите **Сохранить прокси**, затем **Проверить IP** в карточке. При успешном подключении появится **Доступен · IP …**.

Другие опубликованные NordVPN адреса: `se.socks.nordhold.net` (Швеция), `us.socks.nordhold.net` (США), `new-york.us.socks.nordhold.net` (Нью-Йорк). Порт тот же — `1080`. Не каждый обычный VPN-сервер NordVPN является SOCKS5-прокси; используйте список из официальной инструкции.

## 3. Назначьте прокси профилю

Остановите нужный профиль, откройте его настройки, выберите созданный прокси в поле **Прокси** и сохраните изменения. Запустите профиль. Перед открытием браузера программа ещё раз проверит IP через назначенный сервер.

Для другого профиля можно выбрать другой сохранённый прокси. Нескольким профилям также можно назначить один прокси. Выбор разных адресов серверов не гарантирует уникальный или постоянный внешний IP для каждого профиля.

## Если не подключается

- Проверьте, что указаны Service credentials, а не данные входа в аккаунт.
- Проверьте SOCKS5, порт 1080 и адрес из списка NordVPN. Попробуйте другой опубликованный сервер.
- Сеть должна разрешать доступ к серверу NordVPN на порту 1080; для проверки IP нужен доступ к `api.ipify.org` через прокси. Сам SOCKS5 не устраняет блокировку доступа к серверу провайдера.
- Если пароль менялся, остановите назначенные профили и измените сохранённый прокси. Пустое поле пароля при редактировании сохраняет старый пароль.
- При ошибке проверки профиль не запускается и не переключается на прямое соединение. Если прокси пропадёт после запуска, запросы браузера завершатся сетевой ошибкой.

## Как работает и что проверено

Программа автоматически создаёт локальный посредник, который передаёт запросы в выбранный SOCKS5-сервер и выполняет авторизацию. Его не нужно настраивать отдельно. Посредник доступен только на 127.0.0.1 и защищён случайными локальными данными авторизации; после остановки профиля закрывается. Пароль провайдера хранится зашифрованно средствами Windows.

SOCKS5 сам не добавляет шифрования VPN. HTTPS сайтов сохраняет своё шифрование. Это не резидентский прокси и не обещание отдельного постоянного IP. См. [объяснение NordVPN](https://support.nordvpn.com/hc/en-us/articles/19685375790865-NordVPN-Proxy-servers-explained).

Автоматические проверки используют контролируемый SOCKS5-сервер: проверка внешнего IP, настоящий браузер, HTTP и HTTPS-туннели, передача домена для разрешения на стороне прокси, неверный пароль, закрытие и повторный запуск. Подключение к реальному аккаунту NordVPN пока не проверялось: его служебных данных в проекте нет.
