## Review and decisions

Independent review identified and reproduction tests confirmed four issues: WebRTC UDP bypass, loss of a final empty Netscape value, missing duplicate-session snapshots, and merge imports overwriting unhydrated saved session cookies. All four were fixed and retested. Follow-up verified shutdown only saves successfully hydrated sessions, preserves untouched failed-decryption snapshots and handles intentional startup cancellation; no consequential review findings remain.

- Work was performed on `codex/profile-workspace` in the initially empty repository. An unborn HEAD offered no base for a linked worktree; no existing application code was overwritten. This describes the original local delivery before the later public GitHub publication.
- Atomic JSON metadata avoids a native SQLite build dependency. A much larger dataset may eventually need indexed storage.
- Electron Chromium provides the independent engine and isolated persistent storage. This does not claim Dolphin-equivalent fingerprint changes, extension compatibility or universal website compatibility.
- Duplicating a profile copies settings and cookies only. Copying live Chromium LevelDB files was avoided; full Local Storage/IndexedDB migration is not implemented and the UI says so.
- SOCKS5 authentication and partitioned-cookie exchange are explicitly unsupported. HTTP(S) authentication and unauthenticated SOCKS5 remain the supported configuration options; the real authenticated HTTP proxy path was verified.
- Site camera/microphone/location/notification requests are currently denied. A richer browser permission flow is deferred.
- IP checks and proxy startup preflight use ipify; inability to check produces an error rather than direct access.

The portable wrapper was built; automated functional smoke verification targeted its packaged unpacked payload. A separate clean Windows machine, all external account providers, HTTPS/SOCKS5 provider variations and full anti-detection behavior were not verified. These practical limits are also documented in README.
